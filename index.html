🧩 開源係乜？

代碼即文字。唔開源 = 喺你電腦；開源 = 放 GitHub 公開，任人睇 / 複製 / 改。

許可證三類：

  • MIT — 最寬鬆，幾乎冇限制
  • GPL — 最嚴格，用咗你 code 嘅人自己 code 都要開源
  • 唔放 — 法律上默認保留所有權利
💡 老王貼士： 開源 ≠ 放棄所有權。放邊款許可證決定咗別人可以用你代碼做乜。
🔄 Git vs GitHub

兩個名似，但唔係同一回事。

GitGitHub
位置裝喺你電腦網站，跑喺雲端
用途版本控制工具，記錄每次改動，隨時退回任意歷史版本托管 Git 倉庫 + 共享協作平台
聯網單機可用，唔使聯網本地 Git → 推到 GitHub 先有人睇到
打個比喻你電腦上嘅版本記錄本記錄本嘅雲端備份 + 共享平台
✍️ 註冊帳號

github.com → 綠色 Sign up 按鈕

要填四項： 郵箱 · 密碼 · 用戶名 · 國家

  • 推薦 Gmail — QQ/163 成日將驗證信 drop 落垃圾箱
  • 注意 用戶名係永久身份標識，唔好用 test001 呢啲臨時名
  • 安全 密碼用瀏覽器自動生成強密碼，存密碼管理器，唔好同其他站重複
🔗 Gmail 戰略價值： 唔止 GitHub，Supabase / Vercel / Cloudflare 全部支援 Google 一鍵登錄。一個 Gmail 喺 Chrome 裡面就包圓，慳返反覆註冊。

驗證：填完解謎 → 郵箱收 8 位數字驗證碼 → 貼返嚟 → 註冊完成 ✅

🔐 雙重認證 (2FA) — 註冊完第一件事！
⚠️ 強制執行： GitHub 由 2023 年起強制所有做過 code contribution 嘅帳號開 2FA。上傳過檔 / 提過 Issue / 發過 PR，90 日內必須開，唔係嘅話帳號會被限制。

路徑： 頭像 → Settings → Password and authentication → Two-factor authentication → Enable

推薦方式： Authenticator app — 手機下載 Google Authenticator，掃碼綁定，每次登錄除了密碼仲要輸入 App 嘅 6 位動態碼。

🔑 16 個恢復碼： 手機丟咗 / App 刪咗，呢啲係唯一救命鎖匙。

✋ 必須存好： 複製入密碼管理器，或打印出嚟鎖喺抽屜。Android 截圖會存 Google Photos 雲端，用密碼管理器或者實體存更安全。
🏗️ 創建倉庫

右上角 + → New repository

字段說明
Repository name全小寫英文，單詞間用-，例如 my-first-project，唔好用中文
Description一句話講清用途。可填可不填，不過建議填上，日後返睇一眼就明
Public / Private免費帳號兩種都無限建
Add a README file ✅建議勾上 — README 係倉庫塊面，冇 README 嘅倉庫人哋點入嚟即走
Add .gitignore先揀 None，日後需要再整
Choose a license唔打算開源俾人用嘅話就唔使揀

點綠色 Create repository → 倉庫就搞好咗 🎉

🔍 搜索項目

頂部搜索欄直接打字。左邊有類型篩選：切 Repositories 睇倉庫，切 Code 睇代碼內容。

常用限定符（可組合）：

限定符示例效果
language:language:python只搜 Python 項目
stars:stars:>1000星數 > 1000
pushed:pushed:>2024-01-01最近更新時間
topic:topic:web-scraping主題過濾
repo:repo:user/repo精確搜指定倉庫
in:readmeopenclaw in:readme喺 README 入面搜
is:issuebug is:issue is:open搜開放嘅 bug issue
🎯 組合例子： language:python stars:>5000 topic:web-scraping — 精準搵到高質 Python 爬蟲項目
⭐ Star & Fork
  • Star ⭐ — 收藏 / 點讚支持，方便日後找回。好似 bookmark 咁，你嘅 Star list 可以去 github.com/stars/你的用戶名 睇返
  • Fork 🍴 — 複製別人嘅倉庫去你帳號，你可以任意修改，完全唔影響原倉庫
  • Fork 之後用 Pull Request 將你嘅改動提交俾原作者審核合併
💬 老王話： Star 係 GitHub 上最直接嘅感謝。見到好用嘅開源項目，俾個 Star 唔少錢但係對作者好大鼓勵。
🐛 Issue
  • 報 bug、提建議、討論功能嘅地方
  • 可以用 Label 分類：bug enhancement help wanted good first issue
  • 支援 @mention 通知人、#編號 引用其他 issue
  • Issues 可以有 Assignee（負責人）、Milestone（里程碑）、Project（項目板）
📥 本地 Git 基礎

第一次用，設定身份：

git config --global user.name "你的用戶名"
git config --global user.email "你的郵箱"

複製倉庫到本地：

git clone https://github.com/用戶名/倉庫名.git

基本工作流程：

git status          # 睇下有咩改動
git add .           # 暫存所有改動
git commit -m "改咗乜"   # 提交到本地
git push            # 推到 GitHub 備份
git pull            # 拉取遠端最新版本

分支操作：

git branch                    # 睇目前喺邊個 branch
git checkout -b new-feature   # 開新分支並立即切過去
git merge new-feature         # 合併分支返 main
⚠️ Push 密碼問題： 2021 年起 GitHub 唔支援用帳號密碼 push，要用 Personal Access Token (PAT) 或者 SSH key。PAT 喺 Settings → Developer settings 度生成。
🔀 Pull Request (PR)
  • Fork 之後修改代碼 → 提交 PR 俾原倉庫審核
  • PR 入面可以討論、Review code、Request changes
  • 可以開 Draft PR 標示「仲未搞掂，不過俾你睇住先」
  • 合併後你嘅貢獻就入咗原項目 🎉
  • 審核流程：Open PR → Review → Approve → Merge

🔑 Gmail 萬能鎖匙： 上面全部支援 Google 一鍵登錄。一個 Gmail 喺 Chrome 裡面一次過管理晒。
🧠 老王語錄
  • GitHub 唔係程序員專屬 — AI 編程越嚟越強，幾乎人人需要一個 GitHub 倉庫
  • README 一定要有 — 冇 README 嘅倉庫，人哋點入嚟即走，唔會細睇
  • 搜嘢要精準 — 善用限定符，幾億個倉庫都得心應手
  • 開源係雙向嘅 — 唔淨係攞，Star、提 Issue、開 PR 都係貢獻社群嘅方式
