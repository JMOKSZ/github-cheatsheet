🧩 開源係乜？

代碼即文字。唔開源 = 喺你電腦；開源 = 放 GitHub 公開，任人睇 / 複製 / 改。

許可證三類：
  • MIT 最寬鬆，幾乎冇限制
  • GPL 最嚴格，用咗你 code 嘅人自己 code 都要開源
  • 唔放 法律上默認保留所有權利
💡 開源 ≠ 放棄所有權。揀邊款許可證決定咗人哋可以用你 code 做乜。
🔄 Git vs GitHub

兩個名似，但唔係同一回事。

GitGitHub
位置裝喺你電腦網站，雲端
用途版本控制，記錄每次改動托管倉庫 + 協作平台
聯網單機可用推到 GitHub 先有人睇到
比喻版本記錄本記錄本嘅雲端備份 + 分享
✍️ 註冊帳號

github.com → 綠色 Sign up

要填四項： 郵箱 · 密碼 · 用戶名 · 國家

  • 推薦 Gmail — QQ/163 成日將驗證信掉落垃圾箱
  • 注意 用戶名 係永久身份，唔好用 test001
  • 安全 密碼 用瀏覽器生成強密碼，存密碼管理器
🔗 Gmail 戰略價值：Supabase / Vercel / Cloudflare 全部支援 Google 一鍵登錄，一個 Gmail 喺 Chrome 包圓。

驗證：填完解謎 → 郵箱收 8 位驗證碼 → 貼返嚟 → 完成 ✅

🔐 雙重認證 (2FA)
⚠️ 2023 年起強制。做過 code contribution 嘅帳號 90 日內必須開，唔係會被限制。

路徑： 頭像 → Settings → Password and authentication → Two-factor authentication → Enable

推薦方式： Google Authenticator App，掃碼綁定，每次登錄輸入 6 位動態碼。

16 個恢復碼： 手機丟咗 / App 刪咗，呢啲係唯一救命匙。

✋ 密碼管理器或打印鎖抽屜，唔好放雲端截圖。
🏗️ 創建倉庫

右上角 + → New repository

字段說明
Repository name全小寫英文，用 - 分隔，例如 my-first-project
Description一句話講清用途，建議填
Public / Private免費帳號兩者都無限
README ✅建議勾上 — 倉庫塊面，冇 README 人哋點入即走
.gitignore先揀 None
License唔打算開源就唔使揀

點綠色 Create repository → 搞掂 🎉

🔍 搜索項目

頂部搜索欄打字，左邊類型篩選 Repositories / Code。

常用限定符（可組合）：
限定符示例效果
language:language:python只搜某語言
stars:stars:>1000星數過濾
pushed:pushed:>2024-01-01最近更新
topic:topic:web-scraping主題過濾
repo:repo:user/name精確搜指定倉庫
in:readmeopenclaw in:readmeREADME 入面搜
🎯 例子：language:python stars:>5000 topic:web-scraping 精準搵高質爬蟲項目
⭐ Star & Fork
  • Star — 收藏 / 點讚，方便日後找回。可以去 github.com/stars/你的用戶名 睇返
  • Fork — 複製人哋嘅倉庫去你帳號，任意修改，唔影響原倉庫
  • Fork 後用 Pull Request 將改動提交俾原作者審核合併
💬 Star 係 GitHub 上最直接嘅感謝。見到好用開源項目，俾個 Star 好大鼓勵。
🐛 Issue
  • 報 bug、提建議、討論功能
  • Label 分類：bug enhancement help wanted good first issue
  • @mention 通知人、#編號 引用其他 issue
  • 支援 Assignee、Milestone、Project Board
📥 本地 Git 基礎
第一次設定身份：
git config --global user.name "你的用戶名"
git config --global user.email "你的郵箱"
複製倉庫到本地：
git clone https://github.com/用戶名/倉庫名.git
基本工作流程：
git status              # 睇有咩改動
git add .               # 暫存所有改動
git commit -m "改咗乜"  # 提交到本地
git push                # 推到 GitHub
git pull                # 拉取遠端最新版
分支操作：
git branch                    # 睇而家喺邊個 branch
git checkout -b new-feature   # 開新分支並切過去
git merge new-feature         # 合併返 main
⚠️ 2021 年起 GitHub 唔支援帳號密碼 push，要用 Personal Access Token (PAT) 或 SSH key。
🔀 Pull Request (PR)
  • Fork → 修改 → 提交 PR 俾原倉庫審核
  • 可以 Review code、Request changes
  • Draft PR 標示「仲搞掂，俾你睇住先」
  • 流程：Open PR → Review → Approve → Merge 🎉

🧠 老王語錄
  • GitHub 唔係程序員專屬 — AI 編程越嚟越強，幾乎人人需要一個 GitHub 倉庫
  • README 一定要有 — 冇 README 嘅倉庫，人哋點入即走
  • 搜嘢要精準 — 善用限定符，幾億個倉庫都得心應手
  • 開源係雙向 — 唔淨係攞，Star、提 Issue、開 PR 都係貢獻
